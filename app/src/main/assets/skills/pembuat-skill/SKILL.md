# Pembuat Skill

Skill disimpan di `.codeagent/skills/<nama>/SKILL.md` dalam proyek.

1. Tanyakan satu hal: tugas berulang apa yang ingin dibantu skill ini.
2. Tulis frontmatter: `name` (huruf kecil, tanda hubung) dan `description` (satu-dua kalimat: kapan dipakai dan kapan tidak).
3. Isi: langkah singkat bernomor, aturan penting, format keluaran. Padat, tanpa basa-basi.
4. Uji dengan membaca ulang: apakah agen lain bisa mengikuti tanpa konteks tambahan?
